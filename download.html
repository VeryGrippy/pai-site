First run

Install once. PAI handles the setup.

The distribution flow is being built so testers can install PAI like a normal desktop application without manually assembling Python environments, Ollama installs, or model files.

Update safety

Updates should not put your projects at risk.

PAI's updater architecture separates application updates from user projects, verifies published packages, stages the update, and keeps rollback foundations for failed application upgrades.
