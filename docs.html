PAI Docs

Quick-start documentation for the current alpha and the public distribution/update architecture planned for 6.9.

Getting startedModelsProjectsUpdatesChannels

Getting started

Download the Windows installer, launch PAI, choose Local Mode or the available sign-in flow, select a usable coding model, then open an existing project or create a new one.

Models

PAI is designed to be model-independent. Local Ollama models and future external providers are workers controlled by PAI rather than the identity of the product itself.

Projects

Opening a project takes you directly to the Code workspace. Chat is the control surface, Code is the project workspace, and Activity shows what PAI is doing.

Updates

The public 6.9 architecture uses PAIUpdater.exe. PAI checks a small update manifest, verifies the downloaded package, stages it, closes PAI, installs the update, validates the new startup, and can restore a previous known-good build if necessary.

Update channels

Stable is intended for normal users, Beta for preview testers, and Developer for internal/alpha work. Each channel can point at its own latest.json manifest.
