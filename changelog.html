Changelog

Major PAI application milestones. The desktop app itself should show only the newest update by default, with the full history available here or on demand.

Current

6.9 — Distribution, Launcher & OTA Updates

September 2026
  • Native Windows installer and launcher distribution flow.
  • Developer, Beta, and Stable update channels.
  • Verified update packages with SHA-256 validation.
  • Automatic update discovery, staging, restart, health validation, and rollback foundation.
  • Website release information now follows the live release manifest instead of a hardcoded version.

6.4 Alpha 5 — UI Simplification & Navigation Overhaul

September 2026
  • Visible branding simplified from PAI 6 to PAI.
  • New/Open moved beside the brand.
  • Chat, Code, and Activity become the single primary navigation set.
  • Secondary controls moved into Settings and contextual UI.
  • Recent update summary replaces the full changelog on startup.

6.4 Alpha 4 — Application Controls, Model & Recovery

September 2026
  • Local model discovery and explicit Ollama pull controls.
  • Pause, resume, cancel and recovery integration.
  • Stronger application-level settings and updater handoff.

6.3 Alpha 1 — Universal Coding Core

September 2026
  • Project, language, framework and build detection.
  • Universal coding adapters across multiple languages.
  • Language-neutral domain integrity foundation.
