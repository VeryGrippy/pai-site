What happens after installation?

The finished 6.9 flow is designed so users install PAI once and then receive signed, verified updates through PAIUpdater.

1

Install once

The website provides one normal Windows setup/launcher instead of ZIP archives and manual extraction.

2

Update in PAI

PAI checks the selected Stable, Beta, or Developer channel and downloads a verified update package.

3

Recover safely

The updater keeps a known-good backup so failed application updates can be rolled back without touching user projects.
