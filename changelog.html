6.9 — Native PAI-Coder & distribution

September 2026
  • Native PAI-Coder runtime integrated into the desktop application.
  • Automatic first-run model and runtime acquisition architecture.
  • CUDA acceleration with CPU fallback.
  • Windows installer and launcher distribution flow.
  • Developer, Beta, and Stable update channel architecture.
  • Verified update packages, staging, restart validation, and rollback foundations.
  • Public release metadata driven by live manifests.

6.4 — Application experience redesign

September 2026
  • Visible branding simplified to PAI.
  • Projects open directly into the Code workspace.
  • Chat, Code, and Logs established as the primary application surfaces.
  • Secondary controls consolidated into Settings and contextual UI.
  • Editor-style Find replaces a permanent Search destination.
  • Startup focuses on the newest release note instead of dumping full history.

6.4 Alpha 4 — Controls, models & recovery

September 2026
  • Local model discovery and explicit runtime controls.
  • Pause, resume, cancel, and recovery integration.
  • Stronger updater handoff and application settings.

September 2026
  • Project, language, framework, and build detection.

  • Cross-file and domain-integrity foundations.

5.x — Autonomy & application foundations

2026
